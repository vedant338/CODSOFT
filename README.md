# BASIC Data Science Projects

This repository contains multiple machine learning projects completed using Python.

## Projects Included

### 1. Titanic Survival Prediction
Predicts whether a passenger survived the Titanic disaster using machine learning.

### 2. Iris Flower Classification
Classifies iris flowers into different species using ML algorithms.

### 3. Sales Prediction
Predicts future sales using regression techniques.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook
